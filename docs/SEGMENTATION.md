# Частина 3: маска та кандидати в ядра

## Стадії

1. Сила гематоксиліну: strength = 255 - round(255·exp(-cH)).
2. Гістограма 256 рівнів. Для кожного порога t розглядаємо класи
   [0,t] і [t+1,255]. Критерій: n0·n1·(mean0-mean1)² → максимум.
   Нормування на загальну кількість пікселів не змінює оптимальний поріг.
3. Фінальний поріг t_effective=max(t_otsu,threshold_floor).
   Маска: strength > t_effective. Для однорідного кадру маска порожня,
   бо статистичної основи для двокласового розділення немає.
4. Бінарне відкриття: ерозія диском, потім дилатація тим самим диском.
   Диск задається dx²+dy²<=r²; r=1 — хрест із 5 елементів.
   За межами кадру — фон. Ерозія вимагає всі пікселі під диском,
   дилатація — хоча б один. r=0 лишає маску незмінною.
5. Компоненти: знаходимо неперервні серії білих пікселів у кожному рядку.
   Перекриті серії сусідніх рядків об’єднуємо через union-find.
   За 8-зв’язності враховуємо також діагональні дотики.
6. Площа — кількість пікселів компонента; центр — середнє координат
   усіх його пікселів. Відкидаємо компоненти за min_area/max_area і,
   за потреби, за дотиком до межі кадру. Залишені компоненти мають ID 1..N.

Результати 3–6 доступні окремими вкладками й файлами, тому видно,
яка стадія видалила об’єкт. При max_area=0 верхня межа не діє.
Рамка [x_min,x_max) × [y_min,y_max) і координати центру використовують
індекси пікселів від нуля. Номери ставляться біля першого пікселя об’єкта,
тому не гарантується, що текст буде в центрі чи повністю в межах кадру.

## Обмеження

Морфологія може змінювати площу, видаляти дрібні ядра та вузькі структури.
Площа в CSV — площа після відкриття й відбору, не площа ручної розмітки.
Одне злиття кількох ядер поки рахується як один кандидат. Оцу не враховує
локальну неоднорідність освітлення. Порогова сегментація H-каналу не доводить,
що виділена структура є ядром. Фільтри за розміром потребують перевірки
для конкретного збільшення й вибірки. Значення за замовчуванням не є
результатом експериментального підбору.

## Короткі еталони

- Поріг для рівнів 0,1,4: t=1 (міжкласовий критерій 24.5 проти 12.5 для t=0).
- Квадрат 3×3 всередині 5×5 після відкриття диском r=1 стає хрестом із 5 пікселів.
- Діагональ 3×3: три області за 4-зв’язністю, одна за 8-зв’язністю.
- Синтетичний кадр: два квадрати 3×3 та одиночний піксель після відкриття
  й min_area=5 дають два хрести по 5 пікселів.

## Джерело порогового методу

Otsu, N. (1979). A Threshold Selection Method from Gray-Level Histograms.
IEEE Transactions on Systems, Man, and Cybernetics, 9(1), 62–66.
https://doi.org/10.1109/TSMC.1979.4310076

Реалізація виконана через явний перебір порогів; готовий бібліотечний
метод Оцу не викликається. Метрики Dice/IoU та порівняння з розміткою
будуть додані на етапі оцінювання.
