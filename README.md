# Аналіз гістологічних зображень тканин

Індивідуальний STEM-проєкт на Python. Частина 1: завантаження й перегляд.
Потрібні Python 3.10+ та Tkinter (у стандартному інсталяторі Python для Windows).

## Запуск у Windows

Відкрий термінал у теці, де лежить main.py:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```


Натисни «Відкрити зображення». Вибери локальний файл. Програма показує його
назву, розміри та попередній перегляд. Скасування вибору нічого не змінює.
Пошкоджений файл викликає повідомлення, попереднє зображення залишається.
PNG, JPEG, BMP і звичайні TIFF підтримуються; для TIFF читається перший кадр.
Формати сканерів SVS та цілі цифрові препарати поки не підтримуються.

`config.json`: розміри перегляду та максимальна кількість пікселів.
Інша конфігурація: `python main.py --config path/to/config.json`.
Зменшення картинки виконується лише для відображення; оригінал не змінюється.
Поки немає сегментації, підрахунку чи експорту результатів.

## Структура

- main.py — запуск;
- histology/config.py — конфігурація;
- histology/image_io.py — читання зображень;
- histology/app.py — вікно;
- docs/PLAN.md — етапи та проєкт технічного завдання;

Залежності дозволені лише для введення/виведення й візуалізації.
Методи аналізу у наступних частинах реалізовуватимуться вручну.


## Що додано у частині 2

Після відкриття зображення натисни **«Розділити H&E»**. Вкладки:
«Оригінал», «H — гематоксилін», «E — еозин».
Сильніше забарвлені ділянки темніші; H-канал ще не є маскою ядер.
Перемикай вкладки, щоб порівняти однакові ділянки.

Кнопка **«Зберегти канали»** створює нову теку he_* у вибраному місці:
- hematoxylin.png, eosin.png — 8-бітні зображення каналів;
- hematoxylin_od.npy, eosin_od.npy — числові карти float32 у вихідній роздільності;
- parameters.json — назва джерела, розміри, параметри й визначення виходів.

Налаштування `stains` у config.json: вектори барвників у порядку R,G,B,
білий рівень white_level, висота смуги block_rows. Перезапусти програму після
зміни конфігурації. block_rows впливає на пам’ять, не на формулу.
Початкові вектори H=[0.65,0.70,0.29], E=[0.07,0.99,0.11] — наближений
стартовий профіль, а не калібровка конкретного препарату. Зображення іншого
забарвлення або з кольоровим фоном може розділятися погано.

### Перевірки

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

Перевіряються ручний еталон 3×3, неортогональні вектори, чорний/білий,
смугова обробка, помилкові параметри й форма вхідного масиву.
На цьому етапі немає оцінки якості на реальних гістологічних масках.
Подробиці формул і джерела — docs/STAIN_SEPARATION.md.
